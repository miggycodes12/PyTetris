Controls: <br>
W - Rotate piece<br>
A - Move piece left<br>
S - Force piece to fall faster<br>
D - Move piece right<br>
P - Pause/Unpause game

Rare bugs I found during testing. Nonetheless, gameplay should consistenlty be working most of the time:
- When clearing a row, the pieces might not fully fall down and may leave a row of empty tiles.
- Colors of tiles may change when clearing rows.

Uses pygame. Make sure to install it. Pip install and paste into a terminal:
```pip install pygame```
